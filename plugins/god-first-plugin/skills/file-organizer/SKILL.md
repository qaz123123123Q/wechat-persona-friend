# 文件夹整理

## 铁律（先看这段）

1. **默认干跑**。不带 `--apply` 时脚本**只输出方案**，一个字节都不动。必须先把这个方案给用户看，他说"搬吧"才加 `--apply`。
2. **永不删除**。只做移动和改名；遇到重名在文件名后加 `-1`、`-2`。
3. **每次运行都写日志**，`--undo` 能一键撤回。搬完告诉用户日志路径。
4. **跳过正在写入的文件**（默认最近 10 分钟内改动过的跳过，`--min-age-minutes` 可调），避免搬走正在下载的东西。
5. **跳过危险目录**：`.git`、`node_modules`、`__pycache__`、`.codex`、`AppData`、`Windows`、以及任何隐藏文件（除非显式 `--include-hidden`）。
6. **遵守用户的盘符约定**：实体数据放 D 盘，C 盘只放指针。**不要把文件从 D 盘搬进 C 盘**；不确定就问。
7. 只在用户**明确指定的根目录**里活动，不做递归到上级、不跨盘乱搬。

## 用法

先看方案（默认，安全）：

```powershell
python <plugin>\skills\file-organizer\scripts\organize.py --root 'D:\ai\codex\downloads'
```

确认后真搬：

```powershell
python <plugin>\skills\file-organizer\scripts\organize.py --root 'D:\ai\codex\downloads' --apply
```

后悔了，按日志回滚：

```powershell
python <plugin>\skills\file-organizer\scripts\organize.py --undo '<日志路径>'
```

## 分类方式

- **按类型（默认）**：图片 / 视频 / 音频 / 文档 / 表格 / 演示 / 压缩包 / 安装包 / 代码 / 电子书 / 字体 / 其他
- **按日期**：`--by date` → 生成 `2026-10/` 这样的目录
- **按项目**：`--by project` → 用文件名里的常见分隔符（`-`、`_`、空格）取第一个词当项目名，适合素材堆
- **自定义规则**：`--rules rules.json`，形如

```json
{
  "pdf": "文档/PDF",
  "psd": "设计源文件",
  "zip": "压缩包"
}
```

  键是扩展名（不带点，小写），值是目标子目录（可带 `/`）。

## 输出与汇报

脚本会打印：

- 每个分类的**文件数 + 总大小**
- 前 20 条明细（原路径 → 目标路径）
- 干跑时最后一行提示"这是干跑，加 --apply 才会移动"

汇报给用户时用这个顺序：**一共几个文件、分几类、最大的一类是什么、日志会写到哪**。不要一次贴几百行明细。

## 遇到这些情况要停下来问

- 根目录里有 `.git`（可能是代码仓库）→ 确认是不是真的要整理仓库里的文件
- 目标分类会覆盖已有目录里的同名文件 → 说明会用 `-1` 后缀，让用户确认
- 用户想整理的是 `C:\Users\...` 下的目录 → 提醒盘符约定，问清楚是"只归类"还是"搬到 D 盘"
- 单个文件超过 2 GB 或整批超过 20 GB → 先说明再搬
